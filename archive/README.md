# Archive / Legacy Backup

This directory contains legacy, unused, and superseded files archived from the active codebase:

- `server2.py`: The legacy secondary server from the original dual-server Replit setup. All leaderboard processing and database logic are now consolidated into `main.py` and `database.py`.
- `README _FIRST.txt`: University submission instructions from the original 2022 project.
- `error.html`: Old maintenance page with broken static links.
- `cookie.js`: Redundant 5-line script defining legacy globals, now handled natively inside `cookie.html`.
